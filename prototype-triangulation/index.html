Triangulation Restore

Das Bild beginnt als zwei Dreiecke. Schritt für Schritt wird genau dort ein neuer Eckpunkt gesetzt, wo das Dreiecksnetz am stärksten vom Original abweicht; das Netz bleibt dabei eine Delaunay-Triangulierung. Die Farben werden innerhalb jedes Dreiecks linear interpoliert – bis jedes Pixel exakt stimmt.
